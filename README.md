# FinTrack
Personal finance tracking for your spending across categories like food, shopping, and entertainment. 

# Prereqs

- [Node.js] (v18+)
- [PostgresSQL] (v14+)

# Running FinTrack

Terminal 1 (Backend)
cd server
npm install
node index.js

'http://localhost:5000'

Terminal 2 (Frontend)
cd client
npm install
npm run dev

'http://localhost:5173'
